# なぜ作るか

セキュリティ分野は手法の多様化が進んでおり日々情報をキャッチアップしていく必要がある

その中で情報を自分でキャッチアップして理解するというのは困難で時間がかかる

そこで、今週のセキュリティはこれだけ押さえておけばOKという内容を自分で調べてまとめておく

まとめる過程で自分のなかにセキュリティの知識を入れつづ、他の人もそれを見ればおkみたいなサイトがあればいいなとおもう

現在でもそのようなニュースサイトはあるが、一体どこから見ればいいのかわからないという課題があるとおもう

サイトを開く or ニュースページを開いて今週押さえておくべき内容がすぐにわかる

さらに、セキュリティの分野はいろんな攻撃方法があるが、設計で抑えられるようなこともおおい

簡単なものをあげればXSSのようにユーザーの入力をサニタイズせずにページに描画しないとか

そういった実装フェーズにおけるセキュリティの原則もまとめるコンテンツがあるといいし

ニュースページから原則ページに繋げればより学びやすいコンテンツになると思う

# スタイル

ページの閲覧はユーザーにとって心地よいものでなければならない

ユーザービリティは重要だし

ページの見やすさも重要だ

デザインはおしゃれなものにする必要はない

けれど視認性を重視して、イラストやインフォグラフィックで一目でどんなものか伝えることができればいい

また、「なるほど」という体験ができると理解が進みやすくなると思うので

内容によってはインタラクティブコンテンツを作って、だから脆弱性になるんだと思えるようなコンテンツがあるといい
